## 订阅图标仓库

```text
https://raw.githubusercontent.com/pengpoom/poomicon/master/Poomicon.json
```

`Poomicon.json` 收录仓库内所有有效的 108×108 PNG 图标；重名图标会自动附带所在类别，避免在客户端中互相覆盖。

新增或调整图标后，重新生成索引：

```bash
python3 scripts/generate_icon_index.py
```
